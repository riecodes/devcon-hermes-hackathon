The tool

What Hermes is

Hermes Agent is an open-source AI agent from Nous Research, released in February 2026. A chatbot only answers. Hermes takes actions: it runs terminal commands, edits files, browses the web, and calls outside services, then remembers what worked so it gets better at your tasks over time.

Everything lives in one backend folder, ~/.hermes. The terminal, the desktop app and a Telegram bot are three ways into that same agent, so a model, skill or connector you set up once shows up in all of them.

Brain

Model provider

Any LLM: Claude, GPT via ChatGPT sign-in, Gemini, OpenRouter, local Ollama. Swap it with hermes model.

Hands

Built-in tools

Terminal, files, browser, web search, code execution, vision, cron jobs.

Memory

Memory and skills

Persistent memory plus skills: saved procedures it reuses and writes for itself. 53 come built in.

Connectors

MCP servers

Plug-ins for outside services. Tonight: GitHub, Vercel, Neon, Google Workspace.

Doors

CLI, desktop, Telegram

The gateway puts the same agent in Telegram, so it can work from your phone.

Learned the hard way

Gotchas

  1. Memory. Ubuntu plus Hermes needs 1 to 2 GB free. With many Claude sessions and Chrome tabs open, the laptop dropped to 0.6 GB and background jobs got stopped.
  2. libatomic1. Fresh Ubuntu can lack it, and the installer only says "pm install failed". Install it and rerun.
  3. build-essential. hermes desktop compiles native packages on its first build. Without make and gcc it stops at gyp ERR! not ok. Fix: sudo apt install -y build-essential, already done on this laptop.
  4. WSL "device is not ready". Error ConfigureGpu/HCS/0x80070015 means the NVIDIA card was asleep when Ubuntu tried to start. Opening Ubuntu again a moment later worked.
  5. Run sign-ins yourself. Device codes and browser logins work best in your own Ubuntu terminal.
  6. Secrets go in .env. Tokens never go in config.yaml, chat, or the repo.
  7. Restart after MCP changes. Hermes loads connectors at startup; there is no hot reload.
