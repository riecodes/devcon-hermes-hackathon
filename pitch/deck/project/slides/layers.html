How it works

Three layers, one click.

The face

Desktop plugin

A Suki Pulse pane in Hermes Desktop. Pick a branch, click Pulse check. Results come back as native cards.

The playbook

Skill

suki-pulse: pulse check, fix the top cause, recover a customer. It asks before any write.

The hands

MCP server

A pane in Hermes Desktop: a branch picker, four buttons, four Ctrl+K commands. A skill with three workflows: pulse check, fix the top cause, recover a customer.
